It assists users with everyday tasks such as creating fitness plans, generating meal ideas, and writing professional documents. This project strengthened my skills in SwiftUI design, API integration, and natural language processing.

CRDB Customer Advisor Web Application

An AI-powered financial advisor for CRDB Bank Tanzania customers. A customer fills in a profile (age, income, risk appetite, goals, available capital) and gets five product recommendations from CRDB's real catalogue, each with a reason, eligibility note and next step. The Java 17 backend checks DynamoDB for a recent cached result, and if there isn't one, builds a prompt from the profile and product catalogue and sends it to the Google Gemini API, which returns structured JSON. Updating a profile clears the cache so recommendations stay current. The dashboard is built with React, TypeScript and Vite, and I run the backend locally with Docker. I learned prompt engineering, caching strategies and NoSQL data modeling.

Daima Motorcyle Payment Tracking System

A real-time payment tracking and bank reconciliation platform for Daima Motorcycles Ltd in Tanzania, which sells motorcycles on credit. Each credit contract gets a unique customer ID and a CRDB control number. When a rider deposits money through SimBanking, Wakala agents, M-Pesa or internet banking, a webhook endpoint receives the payment, matches it to the right contract by control number, updates the balance and due date, and flags the account as paid off or overdue. Payments with a missing or wrong control number land in an exception queue where staff can match them manually in one click, and a built-in webhook simulator lets me test the whole flow without the live bank. Riders get a mobile portal with their balance, payment guides in Swahili and downloadable e-receipts, and the Google Gemini API generates loan portfolio risk audits and Swahili payment reminders. Built with React, TypeScript, Tailwind CSS and Node.js/Express, bundled with Vite. I learned webhook-driven integrations, payment reconciliation logic and server-side AI integration.
